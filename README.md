# Simon Says - ESP32

A Simon Says memory game built with an ESP32 using C++.

## Features

- OLED display
- 4 LEDs
- 4 push buttons
- Start button
- Passive buzzer
- Random sequence generation
- Level counter
- Win/Loss animations

## Hardware

- ESP32 Dev Module
- SSD1306 OLED (128×64)
- 4 LEDs
- 5 Push Buttons
- Passive Buzzer
- Breadboard
